# Security Policy

## Important

This installer performs a destructive disk operation.

Users must verify that:

- The correct VPS is being used
- A backup exists
- The detected target disk is the intended system disk
- The user understands that the current operating system will be erased

Do not execute the installer on physical servers or unsupported environments.

## Reporting Security Issues

Please report security issues through GitHub Issues or privately to the repository owner.
